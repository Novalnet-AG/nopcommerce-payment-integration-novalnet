# NOVALNET PAYMENT PLUGIN FOR NOPCOMMERCE
Novalnet payment plugin for nopCommerce simplifies your daily work by automating the entire payment process, from checkout to collection. This plugin is designed to help you increase your sales by offering various payment methods on a one-page checkout. The payment plugin is perfectly adjusted to the NopCommerce shop with top-quality range of services of the payment provider.

## NopCommerce Plugin Integration Requirements
<a href="https://www.novalnet.de/">Novalnet</a> merchant account is 
required for processing all international and local payments through this nopCommerce payment plugin. The plugin is available for Supported versions: 4.80.8 - 4.80.9 in the following languages: EN & DE.

## NopCommerce Payment Plugin Installation
Follow these steps to install the Nopcommerce payment plugin by Novalnet:
1. Login to admin → Configuration → Local Plugins.
2. Click Upload plugin or theme, select NovalnetPayment.zip, and upload.
3. Click Restart application to apply changes to complete the upload.
4. Navigate to Configuration → Local Plugins → Novalnet API Configuration and click Install.
5. Configure the Global Configuration and click Configure.
6. Enter the Product Activation Key, Payment Access Key, Client Key, and Tariff ID in the shop admin panel.
7. Enable and activate the preferred payment types in your shop admin panel.
